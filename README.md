# FFXI Journal

FFXI Journal is an Ashita addon for **Final Fantasy XI** focused on providing a unified in-game journal for missions and quests.

It includes mission and quest progression tracking, organized quest categories, objective lists, detailed quest information, Mission and Quest Logs, and controller/keyboard navigation.
